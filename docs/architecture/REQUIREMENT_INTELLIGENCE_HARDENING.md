# Requirement Intelligence Hardening

This release closes the correctness and accessibility gaps identified after the first M1 requirement-intelligence deployment.

## Invariants

1. A contradiction is emitted only when conflicting clauses apply to the same protected resource or action scope.
2. Evidence excerpts remain exact substrings of the supplied requirement; normalized copies are used only for matching.
3. Derived counts and the duplicated brief must agree with the dimension array.
4. The readiness drawer follows a complete modal focus lifecycle.
5. Legacy results clear stale retained assessment state.
6. Programmatic requirement changes refresh the live assessment.
7. Public deployment verification exercises the requirement-intelligence assets and contract.

The hotfix does not add models, credentials, tools, MCP/A2A execution, files, databases, external writes, or broader agent permissions.
