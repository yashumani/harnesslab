# HarnessLab Roadmap

## M0 — Executable Foundation

Repository, monorepo scaffold, web-to-API connection, PostgreSQL persistence, provider-neutral model interface, OpenRouter and Ollama adapters, one bounded temporary worker, structured artifact return, evaluation, trace, timeout, cancellation, and CI.

## M1 — Harness Intelligence

Requirements interview, completeness and contradiction analysis, agent-necessity decision, topology recommendation, MCP/A2A/tool guidance, autonomy matrix, failure analysis, architecture critic, evaluation-plan generation, and visual architecture.

## M2 — Adaptive Agent Runtime

Orchestrator, dependency graph, adaptive subagent controller, context compiler, artifact blackboard, evaluator/judge, concurrency, recursion limits, budgets, retries, fallbacks, and cancellation.

## M3 — MCP and Integrations

MCP clients and server scaffolding, native tools, REST tools, GitHub, databases, retrieval, sandboxed filesystem and command execution, credential isolation, and selective A2A support.

## M4 — Reliability Lab

Simulation, regression evaluations, agent racing, failure injection, prompt-injection tests, model comparison, trace explorer, cost and latency metrics, and routing feedback.

## M5 — Production V1

Authentication, tenant isolation, encrypted secrets, audit controls, environment separation, worker hardening, deployment pipelines, recovery, load testing, security validation, accessibility, and launch documentation.
